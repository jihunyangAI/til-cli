| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-14 | Tampering | packed tarball / `dist/cli.mjs` | medium | mitigate | test-install asserts the tarball holds only `dist/` + `package.json` (no `src/`, `test/`); the static test from 01-03 asserts an LF shebang with no CR; `.gitattributes` from 01-01 keeps checkouts LF |
