## Phase Goal

**As a** single developer who captures learnings from the terminal on Windows, **I want to** install `til` once and record a one-line learning from any shell into today's local-date Markdown file, **so that** every entry is kept exactly as typed — Korean and emoji included — across repeated runs, concurrent runs, and failed writes.

> Derived verbatim from the ROADMAP Phase 1 **Goal:** line (role from PROJECT.md). Run `/gsd mvp-phase 1` if a canonical story should replace it.

<objective>
Expand the tracer's add-only parser into the full D-01..D-05 command grammar and wire every command kind through `run()`: bare words add, reserved first words (`add`, `show`, `list`, `help`), the `--` and `add` escape hatches, `--help`/`--version`, unavailable `show`/`list`, and usage errors with the PowerShell-safe hint.

Purpose: after this plan a user can record text that starts with `-` or a command word, ask for help or the version, and gets exit 2 (never a silent save) for anything ambiguous — the muscle-memory contract every later phase inherits.
Output: `src/core/args.ts` (full grammar), `src/run.ts` (dispatch + USAGE + version), `test/args.test.ts`, `test/cli.test.ts`.
</objective>
